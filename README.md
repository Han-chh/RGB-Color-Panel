# RGB Color Panel

A focused Java Swing utility that turns numeric RGB input into immediate visual color output.

[中文说明](README_zh.md)

## Overview

RGB Color Panel is a compact educational project for understanding how red, green, and blue channels combine. Enter three values from 0 to 255, generate the result, and compare the numbers directly with the rendered color.

## Screenshot

![RGB values and the resulting visible blue color panel](assets/screenshots/rgb-color-panel.png)

The screenshot comes directly from the running Swing utility.

## Features

- Three RGB channel inputs
- 0–255 validation
- Immediate rendered-color feedback
- Enter-key navigation and generation
- Reset control

## Run

The committed JAR was verified with Java 25:

```bash
java -jar RGB-Color-Panel.jar
```

## Scope

The deliberately small interface demonstrates one transformation clearly; no unnecessary framework or service is required.
